이런 점이 좋아요

🖥️

어떤 프로그램이든

데스크톱 앱은 윈도우·맥 화면 전체나 원하는 영역을 녹화합니다. 파일 탐색기, 브라우저 설정, 한글·엑셀, 유니티 모두 됩니다.

🌐

웹사이트는 더 똑똑하게

크롬 확장은 입력칸·비밀번호 칸을 알아보고, 이메일·전화번호 같은 개인정보 후보를 미리 가려 줍니다.

🛡️

개인정보는 선생님 PC 안에

원본 화면은 선생님 컴퓨터에만 암호화해 보관합니다. 학생에게는 가림을 확인·승인한 이미지만 갑니다. 입력한 글자는 녹화하지 않습니다.

🎯

안내 · 연습 · 평가 모드

처음엔 누를 곳을 반짝여 안내하고, 연습에선 두 번 틀리면 힌트, 평가에선 힌트 없이 끝까지. 오답·도움 횟수를 보여 줍니다.

🔑

로그인·서버 없음

학생용 실습은 정적 웹페이지라 무료 호스팅에 올리면 끝. 학생 결과는 학생 화면에만 보이고 어디에도 저장·전송되지 않습니다.

📱

태블릿·크롬북도

더블클릭은 두 번 탭, 오른쪽 클릭은 길게 누르기. 단축키·스크롤 단계는 화면의 대체 버튼으로 할 수 있습니다.

사용법

자세한 내용은 사용 설명서(PDF, 21쪽)에 그림과 함께 있습니다.

1단계

녹화하기

데스크톱 앱: ● 화면 녹화 시작 → 녹화할 영역을 드래그(또는 전체 화면) → 평소처럼 조작 → 도구 막대의 중지.
단축키 Ctrl/⌘+Shift+F8 일시정지, Ctrl/⌘+Shift+F9 중지.

크롬 확장: 녹화할 탭에서 실습 녹화기 아이콘 → 체크 → 이 탭 녹화 시작 → 조작 → 녹화 중지.

클릭·더블클릭·오른쪽 클릭·끌어서 놓기·글자 입력·단축키·스크롤을 알아봅니다. 동작마다 누르기 직전 화면이 한 단계가 됩니다.

2단계

검수함에서 개인정보 가리고 승인

녹화한 장면은 먼저 검수함에 쌓입니다. 개인정보 후보는 이미 검은 상자로 가려져 있고, 이름·사진·알림 등 나머지를 직접 드래그해 가린 뒤 승인합니다.

여러 장을 골라 한꺼번에 승인·버리기할 수 있고, 앱을 닫았다가 나중에 검수해도 됩니다(암호화 보관).

3단계

단계 편집

학생에게 보일 지시문과 두 번 틀리면 보일 힌트를 다듬고, 클릭 영역·확대 영역을 조정합니다. 동작 종류(클릭·더블클릭·끌어서 놓기·글자 입력·단축키·스크롤·선택지 분기)도 바꿀 수 있습니다.

📁 프로젝트에서 언제든 저장·열기, .walksim 파일로 다른 컴퓨터에서 이어서 편집.

4단계

안전 확인 · 학생용 ZIP 내보내기

지시문 속 전화번호·이메일, 이미지 없는 단계, 검수 안 한 장면을 자동으로 찾아 “4단계”처럼 번호로 알려 주고, 누르면 그 단계로 바로 갑니다. 문제가 없으면 학생용 ZIP을 내려받습니다.

5단계

Cloudflare에 올리고 주소 공유

받은 ZIP을 Cloudflare 계정 홈에 끌어다 놓으면 https://이름.workers.dev 주소가 생깁니다. 자세히 보기 ↓

6단계

학생 실습

학생은 안내 · 연습 · 평가 모드를 고릅니다. 주소 끝에 ?mode=guide, ?mode=practice, ?mode=assessment를 붙이면 그 모드로 바로 시작합니다.

설치 방법

Windows
  1. 받은 PracticeRecorder-Windows-Setup-….exe를 실행합니다.
  2. “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누릅니다. (유료 인증서 없이 배포해서 나오는 경고입니다.)
  3. 바탕화면의 실습 녹화기를 실행합니다.
Mac
  1. DMG를 열고 실습 녹화기를 ‘응용 프로그램’ 폴더로 끌어다 놓은 뒤 그곳에서 실행합니다. DMG 창에서 바로 실행하면 화면 기록 권한이 유지되지 않습니다.
  2. “확인되지 않은 개발자” 경고가 뜨면 앱을 우클릭 → 열기. 그래도 안 되면 터미널에서 xattr -cr "/Applications/실습 녹화기.app"
  3. 처음 녹화할 때 macOS 창의 ‘시스템 설정 열기’를 눌러 화면 기록과 손쉬운 사용 목록에서 실습 녹화기를 켜고, 앱을 종료(⌘Q) 후 다시 실행합니다.
  4. 새 버전 설치 후 권한 안내가 계속 뜨면 안내 창의 ‘권한 다시 설정’을 누르세요.
Chrome 확장 프로그램
  1. 받은 ZIP의 압축을 풉니다. (풀린 폴더는 지우지 말고 그대로 두세요.)
  2. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기
  3. 압축해제된 확장 프로그램 로드 → 압축을 푼 폴더 선택
  4. 퍼즐 조각 아이콘에서 실습 녹화기를 고정(📌)해 두면 편합니다.

학생에게 나눠 주기

학생용 ZIP은 더블클릭으로는 열리지 않습니다. 무료 호스팅 Cloudflare에 올려 주소로 엽니다.

  1. dash.cloudflare.com에 가입·로그인합니다(신용카드 불필요).
  2. 계정 홈의 Ship something new(① “Drop a folder, or a zip”) 칸에 받은 ZIP을 그대로 끌어다 놓고 안내에 따라 배포합니다.
  3. https://무작위이름.내계정.workers.dev 같은 주소가 생기면 그 주소를 그대로 학생에게 줍니다. 첫 화면이 실습으로 자동 이동합니다.
  4. 칠판·클래스룸에 주소를 올리거나 QR 코드를 띄웁니다(크롬 주소창 공유 아이콘 → QR 코드 만들기).

올린 사이트 찾기·삭제는 왼쪽 컴퓨트(②). 실습을 고쳤으면 새 ZIP을 같은 칸에 다시 올리세요. Cloudflare 화면은 자주 바뀌니 그림과 다르면 “Drop a folder, or a zip” 또는 “Create app”을 찾으세요.

자주 묻는 질문

정말 무료인가요?

네. 프로그램도 무료이고, 학생용 실습은 Cloudflare 무료 요금제로 올릴 수 있습니다.

학생 개인정보가 서버로 가지 않나요?

학생용 실습에는 서버·로그인·데이터베이스가 없습니다. 학생이 누르거나 입력한 내용은 학생 기기에서만 처리되고 어디에도 저장·전송되지 않습니다. 다만 학생 주소는 링크만 알면 누구나 볼 수 있으니 가상 자료만 올리세요.

녹화할 때 입력한 비밀번호가 남지 않나요?

입력한 글자는 녹화하지 않습니다. 비밀번호 칸은 학생 화면에서 ‘연습용 비밀번호 채우기’ 버튼으로 바뀝니다.

크롬 확장과 데스크톱 앱 중 무엇을 쓰나요?

웹사이트 사용법·사이트 가입은 크롬 확장(입력칸·개인정보 자동 인식), 윈도우·맥 자체나 한글·엑셀·유니티 같은 프로그램은 데스크톱 앱을 쓰세요. 편집기와 결과물은 같습니다.

(Mac) 권한을 켰는데 계속 권한을 달라고 해요.

① 앱이 응용 프로그램 폴더에 있는지 확인 → ② ⌘Q로 완전히 종료 후 다시 실행 → ③ 그래도 안 되면 안내 창의 ‘권한 다시 설정’. 목록에 앱이 없으면 「+」로 응용 프로그램 → 실습 녹화기를 추가하세요.

ZIP을 더블클릭했더니 빈 화면만 나와요.

정상입니다. 브라우저 보안 때문에 웹서버(주소)로 열어야 합니다. Cloudflare에 올리거나, 설명서의 “내 PC에서만 확인하기”를 보세요.

모니터가 여러 대예요.

녹화를 시작하면 모든 모니터에 선택 화면이 뜹니다. 녹화할 모니터에서 영역을 드래그하거나 그 모니터의 ‘전체 화면 녹화’를 누르세요.

학교 홈페이지(LMS) 안에 넣을 수 있나요?

기본 보안 설정이 다른 사이트 안에 끼워 넣기를 막습니다. 주소 링크나 QR 코드로 공유하세요.
