# 실습 녹화기 (Practice Recorder) — AI 어시스턴트용 안내

> 이 문서는 ChatGPT, Claude 같은 AI가 이 프로그램을 정확히 설명하고 사용자를 돕도록 만든 참고 자료입니다.
> 사용자에게 답할 때는 이 문서의 사실만 근거로 쓰고, 적혀 있지 않은 기능은 "없다/확인 필요"라고 답하세요.

## 한 줄 요약
교사가 프로그램을 조작하는 모습을 녹화하면, 학생이 로그인·설치 없이 웹 주소 하나로 똑같이 눌러 보며 연습하는 **인터랙티브 모의 실습(정적 웹페이지)**을 만들어 주는 무료 도구입니다. (Arcade 같은 인터랙티브 데모 방식, 학교 수업용)

## 구성 요소
1. **데스크톱 앱 (Electron)** — 윈도우·맥의 모든 프로그램을 녹화. 영역 드래그 또는 전체 화면, 다중 모니터 지원. 편집기 포함.
   - 단축키: Ctrl/⌘+Shift+F8 일시정지, Ctrl/⌘+Shift+F9 중지. 녹화 도구 막대는 녹화에 찍히지 않음.
2. **Chrome 확장** — 웹사이트 실습 전용. 입력칸·비밀번호 칸 인식, 이메일·전화번호 등 개인정보 후보 자동 가림. 편집기 포함.
3. **편집기** — 검수함(가리기·승인), 단계 편집, 프로젝트 저장·열기, 안전 확인, 학생용 ZIP 내보내기.
4. **학생 플레이어** — 학생용 ZIP 안에 들어 있는 정적 웹 실습.

## 교사 작업 흐름
1. **녹화**: 가상 자료로 화면 준비 → 녹화 시작 → 평소처럼 조작 → 중지. 동작마다 "누르기 직전 화면"이 한 장면이 됨.
   - 인식 동작: 클릭, 더블클릭, 오른쪽 클릭, 끌어서 놓기, 글자 입력(내용은 기록 안 함), 비밀번호 입력, 단축키, 스크롤.
2. **검수함**: 장면마다 개인정보를 검은 상자로 가리고 승인(여러 장 일괄 승인·버리기 가능). 검수 전 장면은 PC에 암호화 보관되어 나중에 검수해도 됨.
3. **단계 편집**: 동작 종류(클릭·더블클릭·오른쪽 클릭·끌어서 놓기·글자 입력·단축키·스크롤·선택지 분기·종료 화면), 지시문, 힌트, 클릭 영역, 추가 가림, 확대 영역. 입력 단계는 정답 값 지정 가능(비우면 아무 값이나 통과).
4. **프로젝트**: 자동 저장. `.walksim` 파일로 저장·열기(다른 PC에서 이어서 편집). `.walksim`에는 검수 전 원본이 들어 있을 수 있어 학생에게 주면 안 됨.
5. **안전 확인 → 학생용 ZIP**: 지시문 속 전화번호·이메일, 이미지 없는 단계, 검수함에 남은 장면을 "N단계"로 알려 주고 클릭하면 이동. 통과 후 `학생용-제목.zip` 내려받기.
6. **배포**: ZIP은 더블클릭으로 열리지 않음. Cloudflare 계정 홈의 "Ship something new / Drop a folder, or a zip" 칸에 ZIP을 끌어다 놓으면 `https://이름.계정.workers.dev` 주소 생성 → 그 주소를 그대로 학생에게(첫 화면이 실습으로 자동 이동). 다른 정적 호스팅도 가능.

## 학생 실습
- 모드: **안내**(누를 곳 강조·설명), **연습**(2번 틀리면 힌트, 3번 틀리면 위치 표시), **평가**(힌트 없음).
- 주소 뒤 `?mode=guide` / `?mode=practice` / `?mode=assessment`로 모드 고정 시작.
- 완료 화면에 오답·도움 사용 횟수 표시. **결과는 저장·전송되지 않음**(LMS 성적 연동 없음).
- 터치: 두 번 탭=더블클릭, 길게 누르기=오른쪽 클릭, 단축키·스크롤은 대체 버튼.

## 개인정보·보안 원칙 (반드시 정확히 전달)
- 원본 캡처는 교사 PC에만 존재(검수 전은 암호화 보관). 학생용 ZIP·공개 사이트·서버로 전송되지 않음.
- 학생에게 가는 이미지는 교사가 승인한 이미지뿐이며, 가림은 픽셀에 새겨져 되돌릴 수 없음.
- 녹화 중 입력한 글자는 기록하지 않음. 비밀번호 칸은 '연습용 비밀번호 채우기' 버튼으로 대체.
- 학생 실습은 서버·로그인·데이터베이스·분석 도구가 없는 정적 페이지.
- 단, 배포 주소는 링크를 아는 누구나 볼 수 있음(검색 노출은 막음) → **가상 자료만** 사용하도록 안내.
- 다른 사이트 안에 끼워 넣기(iframe)는 기본 차단.

## 자주 나오는 문제와 답
| 증상 | 답 |
|---|---|
| ZIP을 더블클릭하면 빈 화면 | 정상. 웹서버(Cloudflare 등)에 올리거나 `python3 -m http.server`로 열어야 함 |
| Mac에서 권한을 켰는데 계속 요청 | 앱을 응용 프로그램 폴더로 옮김 → ⌘Q 후 재실행 → 안내 창의 '권한 다시 설정' |
| Mac "확인되지 않은 개발자" | 우클릭 → 열기, 또는 `xattr -cr "/Applications/실습 녹화기.app"` |
| Windows "PC 보호" 경고 | 추가 정보 → 실행 (코드 서명 인증서 없이 배포) |
| 학생용 ZIP을 편집기에서 열기 | 불가. 편집은 `.walksim` 파일로 |
| 어떤 도구를 쓸지 | 웹사이트 = Chrome 확장, 그 외 모든 프로그램 = 데스크톱 앱 |
| 크롬 확장 설치 | ZIP 압축 해제 → `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 |

## 하지 않는 것 (오해 주의)
- 동영상 녹화 도구가 아님(장면 단위 인터랙티브 실습을 만듦).
- 학생 계정·성적 관리·클라우드 저장 기능 없음.
- AI 자동 지시문 생성, 음성 녹음 기능 없음.
- 모바일(휴대폰·태블릿)에서 녹화는 불가. 학생 실습만 가능.
