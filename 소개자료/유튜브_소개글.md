# 유튜브 업로드용 소개글

## 제목 (하나를 고르세요)

- 실습 녹화기 사용법 | 조작을 녹화하면 학생용 모의 실습이 뚝딱 (무료)
- 클릭 한 번 녹화로 만드는 학생용 모의 실습 — 실습 녹화기 3분 사용법
- 선생님을 위한 무료 수업 도구 ‘실습 녹화기’ 소개와 사용법

## 설명

```
선생님이 프로그램을 조작하는 모습을 녹화하면, 학생이 똑같이 눌러 보며 연습하는 ‘모의 실습’이 만들어집니다.
학생은 로그인이나 설치 없이 주소 하나로 연습할 수 있어요. 실습 녹화기는 무료입니다.

▶ 소개 사이트·다운로드: https://claude-work.janhan97.workers.dev
▶ 모든 버전(GitHub): https://github.com/janghwansangai/claude_work/releases/latest

📌 이런 걸 할 수 있어요
• 웹사이트 실습은 크롬 확장 프로그램으로, 윈도우·맥의 다른 프로그램은 데스크톱 앱으로 녹화
• 누를 때마다 ‘누르기 직전 화면’이 한 장면씩 저장 (입력한 글자 내용은 기록하지 않음)
• 이메일·비밀번호 같은 개인정보 자동 가림 + 직접 가림 상자 그리기
• 지시문 고치기, 네모·화살표·형광펜으로 강조 표시
• ▶ 미리보기로 학생 화면 바로 확인, ↔ 따라 하기로 실제 사이트와 나란히
• 안전 확인 후 학생용 ZIP 내보내기 → 무료 웹 호스팅(Cloudflare 등)에 올리면 주소 완성
• 학생은 안내·연습·평가 세 가지 모드로 스스로 연습
```

## 업로드할 때

- 영상: `실습녹화기_소개영상.mp4` (1920×1080, 30fps, 2분 50초)
- 자막: 유튜브 스튜디오 → 자막 → 언어 추가(한국어) → **파일 업로드** → ‘타이밍 있음’ → `실습녹화기_소개영상_자막.srt`
  (영상에 자막이 이미 새겨져 있으니, 자막 파일은 검색·접근성용으로만 올리거나 생략해도 됩니다. 둘 다 켜면 자막이 두 번 보일 수 있어요.)
- 시청자층: ‘아동용이 아님’ (교사 대상 사용법 영상)
- 합성 콘텐츠 표시: 더빙이 AI 음성이므로, 업로드 화면의 ‘변경되거나 합성된 콘텐츠’ 질문에 실제처럼 보이는 사람·사건이 없다면 보통 ‘아니요’로 충분하지만, 설명란에 ‘AI 음성’이라고 적어 두었습니다.
