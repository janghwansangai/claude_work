# 실습 녹화기 — 최종본

선생님이 프로그램을 조작하는 모습을 녹화해서, 학생이 똑같이 눌러 보며 연습하는 **모의 실습 웹페이지**를 만드는 프로그램입니다.

## 이 폴더에 들어 있는 것

| 폴더 | 파일 | 용도 |
|---|---|---|
| `1_설명서` | **실습녹화기_사용설명서.pdf** | 설치부터 학생 배포까지 그림으로 설명한 설명서 (인쇄용) |
| | 실습녹화기_사용설명서.md | 같은 내용 (GitHub에서 바로 보기) |
| `2_설치파일` | **실습녹화기-크롬확장.zip** | 크롬 확장 프로그램 (웹사이트 실습용) |
| | 데스크톱앱_받는곳.md | Windows·Mac 데스크톱 앱 설치 파일 받는 방법 (파일이 커서 여기 넣지 못함) |

| | 예제_사용법.md | 예제 파일 쓰는 법 |

## 5분 만에 시작하기

1. `1_설명서/실습녹화기_사용설명서.pdf`를 엽니다.
2. 도구를 설치합니다 — 웹사이트 실습은 **크롬 확장**, 윈도우·맥 프로그램 실습은 **데스크톱 앱** (설명서 2장).
3. `3_예제/샘플_학생용_회원가입연습.zip`을 Cloudflare 계정 홈의 **“Drop a folder, or a zip”** 칸에 끌어다 놓아 학생 주소가 어떻게 생기는지 먼저 해 봅니다 (설명서 8장).
4. 내 실습을 녹화 → 검수 → 편집 → ZIP 내보내기 → Cloudflare에 올리기 (설명서 3~8장).

## 개인정보 원칙 (요약)

- 녹화 원본은 **선생님 컴퓨터 안에만** 있고, 학생에게는 **가림을 확인·승인한 이미지만** 갑니다.
- 입력한 글자는 녹화하지 않습니다. 학생의 실습 결과는 저장·전송되지 않습니다.
- 학생 주소는 공개 링크입니다. **가상 자료만** 쓰세요.
