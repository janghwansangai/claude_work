# 데스크톱 앱 설치 파일 받는 곳

Windows 설치 파일(약 110MB)과 Mac 설치 파일(약 130MB씩)은 GitHub 저장소에 넣을 수 있는 크기(100MB)를 넘어서, GitHub가 자동으로 만들어 두는 곳에서 받습니다.

## 받는 방법

1. 아래 주소를 엽니다(GitHub 로그인 필요).
   <https://github.com/janghwansangai/claude_work/actions/workflows/walksim-build.yml?query=branch%3Aclaude%2Fexciting-cori-6e0a3u>
2. 맨 위(가장 최근)의 초록색 ✓ 실행을 누릅니다.
3. 아래쪽 **Artifacts**에서 내려받습니다.

| 파일 | 대상 | 압축을 풀면 |
|---|---|---|
| `실습녹화기-Windows` | Windows 10/11 (64비트) | `실습녹화기-설치-1.0.0.exe` |
| `실습녹화기-macOS` | Mac | `…mac-arm64.dmg` (M1 이후 맥), `…mac-x64.dmg` (인텔 맥) |
| `실습녹화기-크롬확장` | 크롬 | 이 폴더의 `실습녹화기-크롬확장.zip`과 같은 파일 |

- Artifacts는 만든 날부터 **90일** 동안 보관됩니다. 기간이 지났으면 같은 페이지에서 **Run workflow**를 눌러 다시 만들 수 있습니다.
- 설치할 때 나오는 경고와 Mac 권한 설정은 설명서 **2장**을 보세요.
