# 데스크톱 앱 설치 파일 받는 곳

Windows·Mac 설치 파일은 하나가 110MB 이상이라 GitHub 저장소 폴더(파일당 100MB 제한)에 넣지 못하고, **GitHub 릴리스**에 올려 두었습니다.

👉 **<https://github.com/janghwansangai/claude_work/releases/latest>** (GitHub 로그인 필요)

아래쪽 **Assets**에서 내려받으세요. GitHub 첨부 파일은 한글 이름을 쓸 수 없어 영문 이름입니다(PracticeRecorder = 실습 녹화기).

| 파일 | 대상 |
|---|---|
| `PracticeRecorder-Windows-Setup-1.0.0.exe` | Windows 10/11 (64비트) |
| `PracticeRecorder-Mac-arm64-1.0.0.dmg` | Mac — M1 이후 (Apple Silicon) |
| `PracticeRecorder-Mac-x64-1.0.0.dmg` | Mac — 인텔 |
| `PracticeRecorder-Chrome-Extension.zip` | 크롬 확장 (이 폴더의 `실습녹화기-크롬확장.zip`과 같음) |
| `Manual-ko.pdf` | 사용 설명서 (이 폴더의 PDF와 같음) |

- 설치할 때 나오는 경고와 Mac 권한 설정은 설명서 **2장**을 보세요.
- 새 버전을 만들 때: 저장소 **Actions → 실습 녹화기 빌드 → Run workflow**에서 `release_tag`에 새 버전(예: `desktop-v1.0.1`)을 적고 실행하면 릴리스가 만들어집니다. 같은 태그로 다시 실행하면 그 릴리스를 이번 코드로 새로 만듭니다.
