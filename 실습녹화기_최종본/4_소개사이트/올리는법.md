# 소개 사이트 올리는 법

`실습녹화기-소개사이트.zip`은 실습 녹화기를 소개하고 **사용법·다운로드·학생 화면 체험**을 안내하는 웹사이트 전체입니다.

| 주소 | 내용 |
|---|---|
| `/` | 소개 · 사용법(그림) · 다운로드(Windows / Mac / 크롬) · 학생에게 배포 · 자주 묻는 질문 |
| `/demo/` | 예제 실습 “학급 누리집 회원가입” — 학생 화면을 직접 체험 |
| `/files/manual-ko.pdf` | 사용 설명서 PDF |

다운로드 버튼은 GitHub 릴리스의 설치 파일로 연결되며, 새 릴리스를 만들면 자동으로 최신 버전을 가리킵니다.

## 방법 1 — 끌어다 놓기 (가장 쉬움)

1. <https://dash.cloudflare.com> 로그인 → **계정 홈**
2. **Ship something new**(“Drop a folder, or a zip”) 칸에 `실습녹화기-소개사이트.zip`을 그대로 끌어다 놓고 배포
3. 생긴 `https://….workers.dev` 주소가 소개 사이트 주소입니다.

(학생용 실습 ZIP을 올리는 방법과 같습니다. 설명서 8장 그림 참고)

## 방법 2 — Cloudflare와 GitHub 연결 (추천: 한 번 연결하면 GitHub에 올릴 때마다 자동 배포)

Cloudflare가 GitHub 저장소를 직접 지켜보다가 새 코드가 올라오면 스스로 빌드·배포합니다. API 토큰이 필요 없습니다.

1. <https://dash.cloudflare.com> 계정 홈 → **Create app**(또는 컴퓨트 → Workers 및 Pages → 만들기) → **Import a repository / Git 저장소 연결**
2. **GitHub 연결** → Cloudflare GitHub 앱이 `janghwansangai/claude_work` 저장소에 접근하도록 허용 → 저장소 선택
3. 설정값
   | 항목 | 값 |
   |---|---|
   | 프로젝트(Worker) 이름 | `practice-recorder` |
   | 프로덕션 브랜치 | `claude/exciting-cori-6e0a3u` (지금 모든 작업이 있는 브랜치) |
   | 루트 디렉터리 (Root directory) | `website` |
   | 빌드 명령 (Build command) | `bash build.sh` |
   | 배포 명령 (Deploy command) | `npx wrangler deploy` |
4. 저장·배포 → 주소: `https://practice-recorder.<내 계정 하위 도메인>.workers.dev`

화면이 **Pages** 방식으로 나오면: 빌드 명령 `bash website/build.sh`, 빌드 출력 디렉터리 `website/dist`, 루트 디렉터리는 비워 둡니다.
연결된 뒤에는 GitHub 커밋마다 Cloudflare 빌드 결과(✓/✗)가 표시됩니다.

## 방법 3 — GitHub Actions로 자동 배포 (한 번 설정하면 고칠 때마다 자동으로 올라감)

1. Cloudflare → 오른쪽 위 사람 아이콘 → **프로필** → **API 토큰** → **토큰 생성** → 템플릿 **“Cloudflare Workers 편집”(Edit Cloudflare Workers)** → 계정 선택 → 토큰 생성 → 값 복사
2. Cloudflare 계정 홈 오른쪽(또는 Workers 화면)의 **계정 ID** 복사
3. GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
   - `CLOUDFLARE_API_TOKEN` = 1에서 복사한 토큰
   - `CLOUDFLARE_ACCOUNT_ID` = 2에서 복사한 계정 ID
4. 저장소 **Actions → 소개 사이트 배포 → Run workflow**
5. 주소: `https://practice-recorder.<내 계정 하위 도메인>.workers.dev`

이후 `website/` 나 설명서를 고쳐 올리면 자동으로 다시 배포됩니다.
