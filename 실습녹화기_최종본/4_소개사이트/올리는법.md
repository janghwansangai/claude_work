# 소개 사이트

`실습녹화기-소개사이트.zip`은 실습 녹화기를 소개하고 **사용법·다운로드·학생 화면 체험**을 안내하는 웹사이트 전체입니다.
(원본은 저장소의 `website/` 폴더, 다시 만들기: `bash website/build.sh`)

| 주소 | 내용 |
|---|---|
| `/` | 소개 · 사용법(그림) · 다운로드(Windows / Mac / 크롬) · 학생에게 배포 · 자주 묻는 질문 |
| `/demo/` | 예제 실습 “학급 누리집 회원가입” — 학생 화면을 직접 체험 |
| `/files/manual-ko.pdf` | 사용 설명서 PDF |

다운로드 버튼은 GitHub 릴리스의 설치 파일로 연결되며, 새 릴리스를 만들면 자동으로 최신 버전을 가리킵니다.

## 자동 업로드는 하지 않습니다

이 저장소는 소개 사이트를 어디에도 자동으로 올리지 않습니다(예전의 Cloudflare 자동 배포 설정은 지웠습니다).
필요할 때 원하는 정적 웹 호스팅에 이 ZIP의 내용을 직접 올리면 됩니다.

- ZIP 파일은 더블클릭으로는 보이지 않습니다. 내 PC에서 미리 보려면 압축을 푼 폴더에서 `python3 -m http.server` 실행 → <http://localhost:8000>
