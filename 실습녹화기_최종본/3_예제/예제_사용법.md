# 예제 파일 사용법

예제는 가상의 “우리반 누리집 회원가입” 화면을 크롬 확장으로 녹화해 만든 5단계 실습입니다.
(아이디 입력 → 비밀번호 입력 → 약관 동의 → 가입하기 → 완료)

## 샘플_학생용_회원가입연습.zip — 배포 연습

1. <https://dash.cloudflare.com> 로그인 → 계정 홈의 **Ship something new**(“Drop a folder, or a zip”) 칸에 이 ZIP을 그대로 끌어다 놓습니다.
2. 배포가 끝나면 생기는 `https://….workers.dev` 주소를 열어 학생처럼 실습해 봅니다.
3. 다 해 봤으면 왼쪽 **컴퓨트** 메뉴에서 이 사이트를 지워도 됩니다.

## 샘플_편집용_회원가입연습.walksim — 편집 연습

1. 크롬 확장의 **에디터 열기** 또는 데스크톱 앱을 엽니다.
2. 상단 **📁 프로젝트 → 📂 파일 열기…** → 이 파일을 고릅니다.
3. 지시사항·힌트를 바꾸거나 단계를 지워 보고, **✓ 안전 확인 → 학생용 ZIP 내려받기**까지 해 봅니다.
